Native to macOS

PaperMac runs on top of your native Spaces instead of replacing them, so Mission Control, gestures and full-screen apps keep working, and System Integrity Protection stays on.

  • Real macOS Spaces.

    Every Desktop is a real Space with its own Strip. Some Mac tilers swap Spaces for their own workspaces or need System Integrity Protection turned off; PaperMac does neither.

  • Light on your Mac.

    Windows past the screen edge stay live and are never minimized, and on macOS 27 they aren’t redrawn while they’re out of view. On a two-display test Mac, the macOS window system used about two thirds less CPU at idle with PaperMac running.

  • Instant Desktops.

    Switching Desktops skips the slide animation, and a window moves to another Desktop or display in one step.

Floating windows.

Minimized windows.

Native full screen.

Full-screen and Split View windows stay with macOS. The Minimap lists their Spaces, and Option-Tab groups their windows.

What should I know about the beta?

Beta software. PaperMac runs on native macOS Spaces and is built on private macOS APIs, using every tool macOS offers under the hood, so a macOS update can break a feature. We keep finding workarounds and improving PaperMac as macOS changes, and buying Pro supports that work.

What does PaperMac need?

macOS 27 or newer. When you first open it, PaperMac asks for one permission, to move and resize windows, and checks that each display has its own Spaces. Screen Recording is optional and used only by window previews in Pro. See the setup steps.

Does Mission Control still work?

Yes. PaperMac runs on top of native macOS Spaces, so Mission Control keeps working. Full-screen and Split View windows stay with macOS.

How does the Pro trial work?

The Pro trial lasts up to 14 days: the first 7 start after setup in the app, and you can extend it once by 7 more. When it ends, PaperMac returns to the free version and keeps your layout.

Install PaperMac

Free to use, with no time limit. Built for macOS 27.

  1. Install it

    Download for Mac

    Or use the install script. Read it first

    By downloading, you agree to the Terms.

  2. Let PaperMac move and resize windows

    Open PaperMac. Its setup window takes you to the right place in System Settings: under Privacy & Security › Device Control and Data Access, turn on PaperMac. This is the macOS permission that lets an app move and resize other apps’ windows, which is how PaperMac lays them out on the Strip.

  3. Keep separate Spaces for each display

    PaperMac needs Displays have separate Spaces on, in System Settings › Desktop & Dock › Mission Control, so each display keeps its own Desktops. If you turn it on now, log out and back in to finish.

PaperMac starts arranging your windows as soon as both are on.

Optional, for specific features

Screen Recording
Only for window previews in PaperMac Pro: hover a window in the Minimap or the switcher to see it. macOS asks for Screen Recording before any app can show what’s inside another app’s windows. PaperMac doesn’t send window contents anywhere. Quit and reopen PaperMac after you allow it.
macOS edge tiling
The setup window can turn it off for you. Then dragging a window to a screen edge reorders the Strip instead of snapping the window to half the screen.
Input Monitoring
You don’t grant it separately. On macOS 27 it comes with Device Control and Data Access after PaperMac reopens, so you may see PaperMac listed there too.

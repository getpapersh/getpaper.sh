PaperLand Alpha · Linux / Omarchy

Your windows. Room to move.

Full-width windows in scrolling Strips, a Minimap to keep your place, and Overview to scan your Desktop and jump to a window.

Built for Hyprland's native workspaces. Inspired by PaperWM and niri.

Install PaperLand Alpha

Install on Omarchy

Requires Omarchy 4+ and Hyprland 0.56+, with Quickshell, Python 3, git and jq. Other Linux desktops are not supported by this installer.

Read the script first · Source and changelog

The installer validates the pinned plugin release before publishing it, installs the runtime and configures your shortcut and autostart. No sudo. If your Hyprland config is symlinked, follow the printed include instructions or explicitly choose --edit-dotfiles.

When setup finishes, open the Minimap with Super + M by default. Run the same command again to update. After an update, use paperland stop && paperland start-hidden as instructed.

Alpha software. Expect rough edges. Review the installer output and keep your config backups.

Open source for Linux.

Uninstall PaperLand

Run curl -fsSL https://getpaper.sh/install | sh -s -- --uninstall. Your settings and config backups are kept.

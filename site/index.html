Paper

Scrolling tiling for macOS + Hyprland.

curl -fsSL https://getpaper.sh/install | sh

On macOS it installs PaperMac. Paperland for Hyprland is coming soon. To update, run it again. Read the script before you run it.

macOS: PaperMac

curl -fsSL https://getpaper.sh/install | sh

Homebrew: coming soon.

Uninstall

curl -fsSL https://getpaper.sh/install | sh -s -- --uninstall

If PaperMac crashed or was force-quit, open it once and quit it before uninstalling, so it can return any hidden windows.

Requirements

  • macOS 27 or newer.
  • PaperMac is an alpha and is not notarized yet, so it installs through the command above only.
